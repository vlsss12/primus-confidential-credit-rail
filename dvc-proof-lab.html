The Rust test and the browser lab share this versioned vector file. GitHub Actions runs the Rust core suite on pushes and pull requests. The browser runner is an illustrative conformance check—not signature verification, DVC-service execution, SP1 execution, or a cryptographic proof.

    

    

      
The policy digest is recomputed from canonical JSON using Web Crypto. Rule evaluation uses integer fixed-point arithmetic, mirroring the Rust core. The simulated source/template/subject/expiry checks are conformance fixtures, not Primus cryptographic verification. Primus's documented DVC architecture verifies the TLS attestation before business logic runs in a zkVM/TEE; this website does not claim that end-to-end path is live.
